# Runway Seed Audio — Korean recording scripts

25 clips cover all 122 conversation lines. One clip per speaker per conversation.

**Settings in Runway:** Audio → model **Seed Audio 1.0** → pick a Korean-sounding voice.
Use the SAME voice for every clip belonging to the same character, and a
DIFFERENT voice for the other character in that conversation.

Paste the block exactly as written — the blank lines are deliberate, they
create the gaps that let each clip be split back into individual lines.

Name each download after its heading, e.g. `C1-A.mp3`.

---
